# Digger — поиск datasheet по фото микросхемы

Программа для Windows 7 (и новее). Вы перетаскиваете в окно вырезанные с фото плат
микросхемы, программа:

1. улучшает изображение и читает маркировку (Tesseract, без интернета);
2. определяет партномер, исправляя типичные ошибки распознавания (O↔0, I↔1, S↔5, B↔8…);
3. ищет datasheet в вашей базе на сетевых дисках;
4. если не нашла — ищет в интернете по уровням (каталоги, производитель, Китай, форумы, базы SMD-кодов, GitHub),
   скачивает PDF в карантин, проверяет, что это действительно документ на этот чип, и кладёт его в вашу базу;
5. сверяет чип с datasheet (партномер, маркировка, корпус, число выводов, производитель);
6. даёт заключение: **есть ли в микросхеме память** (Flash, EEPROM, OTP, EPROM, PROM, SRAM, DRAM, FRAM, NVRAM),
   какая именно, энергонезависимая ли и какого объёма — с указанием, на чём основан вывод.

## 1. Установка

### Портативная версия (рекомендуется, без установки и прав администратора)
1. GitHub → Releases (или Actions → последняя сборка → Artifacts) → `Digger_portable_win7_x64.zip`.
2. Распакуйте в свою папку, например `D:\Digger` или в профиль пользователя.
3. `Самопроверка.bat` — должно быть «САМОПРОВЕРКА ПРОЙДЕНА», отчёт в `logs\selftest.txt`.
4. Запуск — `Digger.bat`. Внутри уже есть Python 3.8.10, пакеты и Tesseract (`tesseract\`);
   программа пишет только в свою папку. Состав сборки — `build_info.txt`.

Сборка: `python tools/build_portable.py` (на Mac без 7-Zip — с ключом `--no-tesseract`, для проверки состава). PP-OCR (rapidocr-onnxruntime с моделями, onnxruntime 1.11.1) ставится в `python/Lib/site-packages` из `requirements.txt`, DLL Visual C++ кладутся рядом с `python.exe`.

### Установка с Python (старый способ)

#### Что нужно
| Что | Где взять | Примечание |
|---|---|---|
| Python **3.8.10** x64 | python.org → Downloads → Windows → `python-3.8.10-amd64.exe` | Последняя версия Python с установщиком для Windows 7. При установке отметьте **Add Python to PATH**. На Windows 7 SP1 нужно обновление KB2533623 (обычно уже стоит). |
| Tesseract OCR | github.com/UB-Mannheim/tesseract → Releases (или wiki «Tesseract at UB Mannheim») | Ставьте в `C:\Program Files\Tesseract-OCR`. Если свежая 5.x не запускается на Windows 7 — возьмите более старую сборку 5.x или 4.1. Достаточно английского языка (eng). |
| Пакеты Python | архив `Digger_wheels_win7_x64.zip` | Распакуйте в папку `wheels` внутри программы — установка пройдёт **без интернета**. Без неё пакеты будут скачаны с PyPI. |

#### Шаги
1. Распакуйте программу, например в `C:\Digger` (путь лучше без русских букв).
2. Распакуйте архив пакетов так, чтобы получилось `C:\Digger\wheels\*.whl`.
3. Запустите `install_win7.bat`. Он создаст окружение `venv`, установит пакеты и запустит самопроверку
   (4 тестовых чипа — должно быть «ИТОГ: всё верно»).
4. Запуск — `run.bat` (фото можно перетаскивать прямо на этот файл).

Если хотите одну папку с `Digger.exe` без установки Python на другие компьютеры — запустите `build_exe.bat`
(результат в `dist\Digger`). Tesseract на этих компьютерах всё равно нужен.

### Первая настройка («Настройки…»)
* **Папки с datasheet** — ваши сетевые диски (`\\server\share\datasheets` или `Z:\datasheets`). Программа их только читает.
* **Папка для скачанных datasheet** — сюда складываются найденные в интернете документы. Это и есть ваша новая база;
  её удобно указать на сетевом диске, чтобы пользовались все.
* Затем **База → Индексировать папки** (повторяйте, когда на дисках появляются новые файлы).
* Необязательно, но очень полезно: **База → Импорт каталога деталей** — см. раздел 5.

## 2. Работа

1. Перетащите фото (или целую папку) в список слева.
2. Нажмите **Распознать**. Для каждого фото появится партномер и пометка «ПАМЯТЬ / без памяти».
3. Если маркировка прочитана неверно — исправьте текст в поле «Маркировка» и нажмите «Пересчитать».
   Можно выбрать другой вариант партномера из списка или вписать свой.
4. Укажите корпус и число выводов, если оценка по фото неточна — это улучшает сверку.
5. Метка «нет в базе» после распознавания значит: в локальной базе datasheet нет, в интернете ещё не искали.
   **Быстрый поиск** — сначала база, потом сайты и поисковики, до первого подтверждённого datasheet;
   **Полный поиск** — пройти все источники, не останавливаясь на первом найденном. Те же кнопки есть
   в карточке чипа («Быстрый», «Полный»), «Далее» — перейти к следующему фото. Метка «не найдено» —
   в интернете искали, подходящего документа нет.
6. Вкладка «Документы»: двойной щелчок по строке — использовать документ; ссылки на сайты вне белого
   списка программа не открывает, их можно открыть вручную в браузере.
7. **Сохранить отчёт** (HTML по одному чипу) или **Сводка CSV** (таблица по всем фото, открывается в Excel).

Как показать программу другим (сценарий на эталонных чипах: где лежит скачанный PDF, на чём основано
заключение, что попадает в отчёт и в сводку CSV) — `docs/DEMO.md`; в сборке — «КАК ПОКАЗАТЬ ПРОГРАММУ.txt»
в папке программы, в окне — меню «Справка» → «Как показать программу».

### Советы по вырезке фото
* Режьте с небольшим полем вокруг корпуса — программа сама найдёт корпус и посчитает выводы.
* Лучше всего читается текст высотой от 15 пикселей на исходном фото. Если снимаете специально —
  свет сбоку под углом (гравировка становится контрастной) и без бликов.
* Поворот (0/90/180/270°) и небольшой наклон программа исправляет сама.

## 3. Модули (меняются независимо)

Программа — это конвейер из 9 модулей. Какой класс выполняет каждую роль, задаётся в `config.json → modules`.
Чтобы заменить модуль, напишите класс-наследник интерфейса из `digger/core/interfaces.py`,
положите файл в папку `plugins/` и укажите его в `config.json`. Пример — `plugins/example_memory_plugin.py`.

| Роль | Модуль по умолчанию | Что делает |
|---|---|---|
| `enhancer` | `enhance_opencv` | находит корпус, увеличивает, выравнивает наклон, делает 7 вариантов контраста/бинаризации (в т.ч. для лазерной гравировки) |
| `ocr` | `recognition.manager` | цепочка провайдеров распознавания: PP-OCRv4, запасной Tesseract; свой способ — папка `plugins/ocr_<имя>/` (`provider.json` + `provider.py`, см. `digger/recognition/api.py`) и его id в `config.json → recognition.chain` |
| `identifier` | `identify_rules` | партномер из текста, исправление похожих символов, коды дат/партий, склейка строк, оценка корпуса и выводов |
| `local_db` | `localdb_sqlite` | индекс сетевых папок, библиотека скачанного, кэш текста PDF, каталог деталей |
| `web_search` | `acquire.websearch` | многоуровневый безопасный поиск и скачивание |
| `pdf_text` | `pdftext_pypdf` | текст из PDF (ничего из PDF не исполняет) |
| `comparator` | `compare_basic` | сверка фото и datasheet |
| `memory` | `memory_rules` | заключение о памяти |
| `report` | `report_html` | отчёт |

Справочники, которые можно дополнять без программирования:
* `data/part_rules.json` — семейства чипов (регулярное выражение → семейство, производитель, какая память, как считать объём);
* `data/sources.json` — источники поиска, запросы, порядок уровней, белый список сайтов.

## 4. Интернет-поиск: уровни и источники

| Уровень | Что | Как |
|---|---|---|
| 1. Каталоги datasheet | AllDatasheet, Datasheet Archive, FindChips, datasheetspdf, datasheet4u, LCSC, Mouser, DigiKey, Farnell | прямые страницы поиска + поисковики с `site:` |
| 2. Производитель | сайт производителя по логотипу/префиксу (ST, TI, Microchip, WCH, GigaDevice, Winbond, Macronix, Espressif, Holtek, STC, Padauk, Puya…) | `site:` поиск |
| 3. Китайский интернет | 立创商城 LCSC/szlcsc, 半导小芯 Semiee, 电子发烧友 elecfans, 21ic, dzsc, EEWorld, 51hei, amobbs, icpdf; поисковики Baidu, Bing China, Sogou, 360 | запросы «数据手册», «规格书» |
| 4. Форумы инженеров | EEVblog, Electronics StackExchange, Badcaps (ремонт плат), Reddit, electronix.ru, radiokot, cxem, kazus, vrtp | поисковики с `site:` |
| 5. Базы SMD-кодов | s-manuals, alltransistors, smd.yooneed.one + запросы «SMD marking code», «丝印», «маркировка SMD» | для коротких кодов на мелких корпусах (SOT-23 и т.п.) |
| 6. GitHub | репозитории с документацией и прошивками | API GitHub |

Поисковики общего назначения: DuckDuckGo, Bing, Mojeek, Brave, Яндекс (Google выключен — он блокирует автоматические запросы).
Если поисковик недоступен или просит капчу, программа переходит к следующему.

**Мои дополнительные предложения** (часть уже встроена):
* **Каталог деталей KiCad** (встроено: импорт) — десятки тысяч деталей с описаниями и ссылками на datasheet, работает
  без интернета. Скачайте архив библиотек символов KiCad с GitHub (репозиторий `KiCad/kicad-symbols`, кнопка
  Code → Download ZIP) и импортируйте через «База → Импорт каталога». Даёт описание вида «I2C Serial EEPROM, 2Kb»,
  что помогает и опознанию, и выводу о памяти.
* **CSV-каталог** (встроено) — например, выгрузка библиотеки деталей JLCPCB/LCSC или ваша собственная таблица
  `part;description;manufacturer;package;datasheet_url`.
* **Базы SMD-кодов и китайское «丝印»** (встроено) — на китайских чипах в SOT-23/SOT-89 вместо партномера
  стоит 3–4-символьный код; искать его надо именно так.
* **Сайты производителей по логотипу** (встроено по тексту логотипа). Следующий шаг — распознавание логотипов
  по картинке (отдельный модуль).
* **API дистрибьюторов** (для следующей версии, когда откроют доступ): Nexar/Octopart, Mouser, DigiKey, LCSC —
  точные параметры, корпуса, ссылки на официальные PDF; нужен бесплатный ключ.
* **Облачное распознавание фото мультимодальной моделью** (Claude и т.п.) как дополнительный модуль `ocr` —
  заметно лучше читает стёртую маркировку и логотипы. Подключается заменой модуля, когда будет разрешён доступ.
* **Дообучение Tesseract** на ваших вырезках — положите свою модель в папку `tessdata` рядом с программой
  и укажите её в `config.json → module_settings → ocr → lang`.

## 5. Безопасность

* Программа обращается **только к доменам из белого списка** (`data/sources.json` + `config.json → network.allowed_domains`).
  Ссылки на другие сайты показываются, но не открываются и не скачиваются. Каждый редирект проверяется заново.
* Только HTTPS (http — лишь для доменов, явно перечисленных в `network.allow_http`), сертификаты проверяются всегда.
  Запрещены IP-адреса, локальная сеть, нестандартные порты, `file://`.
* Ограничения размера страниц и PDF, таймауты, пауза между запросами к одному сайту.
* Скачанное должно быть настоящим PDF (сигнатура `%PDF-`). Файл попадает в **карантин**
  (`data/quarantine`, чистится через 7 дней), проверяется на активное содержимое (JavaScript, запуск программ,
  вложенные файлы, XFA) и на то, что в тексте есть искомый партномер. Только после этого — в библиотеку.
  Подозрительные файлы остаются в карантине. Проверка сигнатур базовая (сжатые потоки не распаковываются),
  поэтому скачанные PDF открывайте просмотрщиком с отключённым JavaScript (например, SumatraPDF).
* Текст PDF читается библиотекой pypdf (чистый Python), ничего из PDF не исполняется. Программа сама ничего
  не запускает и не открывает.
* Cookies хранятся только в памяти. В сеть уходит только текст маркировки/партномер — фото никуда не отправляются.
* Все обращения пишутся в `logs/network_audit.log` (дата, адрес, код ответа, размер) — удобно для администраторов.
* **Автономный режим** в настройках полностью отключает интернет.

### Как получить доступ у администраторов
«Сеть → Диагностика» проверит все источники и покажет, какие открыты. Кнопка «Сохранить список закрытых сайтов»
создаёт готовый текст запроса с перечнем доменов. Если доступ будет через прокси — укажите его в настройках.

## 6. Ограничения первой версии (честно)

* Tesseract плохо читает сильно стёртую, очень мелкую или закрытую бликом маркировку. Тогда впишите текст вручную —
  дальше всё работает так же.
* Шаблоны адресов сайтов и разбор выдачи поисковиков проверены на примерах страниц, но из этой среды разработки
  не было доступа к самим сайтам. Сайты меняются, часть рисуется JavaScript'ом (LCSC, Mouser, DigiKey) —
  такие дают мало результатов напрямую, но находятся через поисковики. После первой диагностики у вас может
  понадобиться поправить `data/sources.json`.
* Число выводов по фото — оценка (работает, когда на вырезке видны выводы вокруг корпуса). BGA/QFN снизу не видны —
  укажите корпус вручную.
* Datasheet-сканы без текстового слоя читаются распознаванием (Tesseract, английский текст): первые 4 и
  последние 2 страницы; в «Почему» у такого документа пометка «текст распознан с картинок страниц».
  Скан, который прочитать не удалось, получает «Нужно ваше решение».
* Вывод «памяти нет» для незнакомых семейств основан на отсутствии упоминаний в datasheet — проверяйте
  уверенность в заключении.
